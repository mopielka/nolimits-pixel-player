# Pixel floor player

The built web player for animations made for the **Pixel** LED floor (28 × 16 tiles, 25 fps). It shows an animation on a 3D model of the floor in a dark dance hall, from above, from either long side, from the entrance, or freely with the mouse.

**Live:** https://mopielka.github.io/nolimits-pixel-player/

You can drop onto the page an animation package (ZIP with `index.json`), a bare `index.json`, or a ZIP of finished `klatka_NNNN.png` frames.

This repo only holds the generated site and is overwritten on every deploy – don't edit it. The source, the animation format and instructions (for people and for Claude) are in **https://github.com/mopielka/nolimits-pixel**.
